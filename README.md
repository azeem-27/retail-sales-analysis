# Retail Sales Analysis

This project was created in Microsoft Excel, analysing retail transaction data to identify sales patterns across product categories, time periods and customer demographics.

## Dataset
The dataset contains 9 fields:
- Transaction ID
- Date
- Customer ID
- Gender
- Age
- Product Category
- Quantity
- Price per Unit
- Total Amount

## Analysis
- Reviewed the dataset for missing values, duplicate entries and extreme values.
- Calculated Sales KPIs
- Used PivotTables to analyse:
  - Product category
  - Monthly sales
  - Age groups
  - Gender
- Created a monthly revenue trend chart
- Identified patterns and areas for further investigation

## Key Skills Demonstrated
- Data validation
- Excel PivotTables
- Number Formatting
- Data Visualisation
- Presenting Findings

## Files
- `retail_sales_analysis.xlsx` — contains the dataset and analysis
- `findings.md` — key findings and follow up questions
- `raw_data.csv` — an unaltered version of the dataset

## Limitations
The dataset provides information about transactions and sales. But it does not include data on profit margins, discounts or inventory levels. Therefore, the analysis identifies sales patterns rather than profitability or causation.
